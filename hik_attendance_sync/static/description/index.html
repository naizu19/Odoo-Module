Why Choose This Integration?

Smart attendance synchronization between HikCentral and Odoo

This module establishes a direct pipeline between your HikCentral Professional System and your Odoo Database. It completely eliminates the need for manual data imports or third-party middleware.

How it works: The module directly listens to and fetches attendance events from the HikCentral system. The absolute moment an employee interacts with a physical device—whether via face recognition, fingerprint scan, or access card swipe—at any branch terminal, the event logs are automatically fetched and pushed straight into your Odoo database to generate live check-in and check-out entries.

Step 2

Verify the module icon and module name.

Step 3
