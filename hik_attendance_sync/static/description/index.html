Why Choose This Integration?

Smart attendance synchronization between HikCentral and Odoo

This module establishes a direct pipeline between your HikCentral Professional System and your Odoo Database. It completely eliminates the need for manual data imports or third-party middleware.

How it works: The module actively captures attendance transaction logs directly from the HikCentral system. The absolute moment an employee registers an event at any physical terminal—whether via facial recognition, fingerprint scan, or access card swipe—the payload is instantly captured. The system automatically fetches, maps, and pushes these logs straight into your centralized Odoo database, generating accurate, live check-in and check-out attendance records across all branch locations.
