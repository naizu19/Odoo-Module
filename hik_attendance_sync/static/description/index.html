Detailed Configuration Guide

Action Buttons

Sync Attendance: A manual override button that fetches all access records from the server immediately. Ideal for initial testing.

Subscribe Webhook: Registers your Odoo endpoint with HikCentral to enable instant, real-time data "push" notifications.

API & Credentials

Base URL: The IP address and port where your HikCentral OpenAPI service is hosted.

App Key & Secret: Unique identifiers provided by HikCentral for secure authentication.

Webhook URL: The public-facing address where HikCentral will send live event data.

Sync Control

Event Selection: Independently toggle Face, Fingerprint, or Card events to filter data entry.

Duplicate Threshold: Prevents duplicate entries if an employee scans their ID multiple times within the same minute.

Sync Interval: Defines how often the background service checks for updates.

🔄 Operational Workflow

Input: Enter your HikCentral Credentials → Validate: Click "Sync Attendance" to confirm handshake → Live: Click "Subscribe Webhook" for automatic real-time updates
